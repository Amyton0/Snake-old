# Змейка

Старая версия 2019 года, для архива.

Игра на Python с использованием библиотеки pygame, где змея, состоящая из круглых сегментов двигается по полю, ест еду и спасается от “врагов”, в которых ей нельзя врезаться, иначе она погибнет. Мной реализована вся игра, то есть передвижения змейки, кнопка паузы, начисление очков, передвижение “врагов” и гибель змейки.

## Инструкция по запуску

Установка зависимостей
```
# Windows
python -m pip install --upgrade pip
pip install -r requirements.txt

# macOS и Linux
python3 -m pip install --upgrade pip
pip3 install -r requirements.txt
```

Запуск игры
```
# Windows
python main.py

# macOS / Linux
python3 main.py
```
